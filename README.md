# Sorting algorithms

This project contains sorting algorithms such as **insertion sort** (`sort1`), **bubble sort** (`sort2`), **selection sort** (`sort3`), **merge-sort** (`sort4`) **quick-sort** (`sort5`) and the **merge** (`merge`) methode used in the **merge-sort** algorithm. It also contains tests for all these algorithms. The code is written in TypeScript and an auto-generated JavaScript version.
